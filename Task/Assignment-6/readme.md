# Two Leaves and A Bud – Website Recreation

This project is a frontend recreation of the official **Two Leaves and A Bud** website.

The purpose of this project is purely for:

- Learning
- Practice
- Improving frontend development skills
- Understanding modern website layouts and animations

This is **not** an official website and is **not intended for commercial use**.

All original designs, images, branding, and content belong to their respective owners.

## Tech Used

- HTML
- CSS
- Tailwind CSS
- JavaScript

## Note

This project is created only for educational and study purposes.
