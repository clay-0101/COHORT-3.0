Library 01 · GSAP

GreenSock Animation Platform (GSAP)

GSAP is a JavaScript library that animates almost any property of almost any element — position, rotation, scale, opacity, colors, even SVG shapes — smoothly and with precise control over timing. It works the same way in plain HTML/JS as it does in any framework, which is exactly why it's the best place to start.

Getting the CDN & connecting it

Add the GSAP script tag in your <head>, or right before your closing </body> tag — either works, since GSAP doesn't need to wait for the page to load. What matters is that your own script (the one that calls gsap.to() etc.) is loaded after the GSAP script tag, so the gsap object already exists when your code runs.

index.html — where to place it
<head>
  <script src="https://cdn.jsdelivr.net/npm/gsap@3.13.0/dist/gsap.min.js"></script>
</head>
<body>

  <div class="box"></div>

  <!-- your own file, loaded LAST, after the elements exist -->
  <script src="script.js"></script>
</body>
script.js — confirm the connection
console.log(gsap);
// If this prints the GSAP object (not "undefined"), you're connected.
01

Basic Tweens — to(), from(), fromTo()

A "tween" is a single animation from one state to another. gsap.to() animates from the element's current state to the values you give it. gsap.from() does the reverse — it starts at the values you give it and animates to the current state. gsap.fromTo() lets you set both the start and end explicitly.

script.js
gsap.to(".box", {
  x: 300,
  rotation: 360,
  duration: 1.5,
  ease: "power2.out"
});
Project idea

A single square that slides across the screen and spins once, the moment the page loads. Try swapping gsap.to() for gsap.from() and see how the animation direction flips.

02

Easing & Duration

The ease property controls the "personality" of the motion — a linear move feels robotic, "power2.out" feels natural, "bounce.out" feels playful, "elastic.out" feels springy. duration controls how many seconds the tween takes.

script.js
gsap.to(".ball", {
  y: 300,
  duration: 1,
  ease: "bounce.out"
});
Project idea

Drop three balls down the same distance, each with a different ease ("power1.in", "bounce.out", "elastic.out") so you can visually compare how each one feels.

03

Timelines — Sequencing Animations

A timeline lets you chain multiple tweens so they play in order (or overlap on purpose). This is how you build multi-step animations like an intro sequence, instead of nesting callbacks.

script.js
const tl = gsap.timeline({ defaults: { duration: 1, ease: "power2.out" } });

tl.to(".logo", { opacity: 1, y: 0 })
  .to(".headline", { opacity: 1, y: 0 }, "-=0.5")   // starts 0.5s before the previous ends
  .to(".cta-button", { opacity: 1, scale: 1 });
Project idea

An "intro sequence" for a page: a logo fades in first, then a headline slides up, then a button pops in last — all in one connected flow.

04

Stagger — Animating Groups of Elements

When you animate a group of elements (like a set of cards), stagger adds a small delay between each one, so they animate one after another instead of all at once.

script.js
gsap.to(".card", {
  y: 0,
  opacity: 1,
  duration: 0.6,
  stagger: 0.15,
  ease: "power2.out"
});
Project idea

A grid of 6–8 cards that starts invisible and slightly lower, and staggers into place one by one when the page loads.

05

ScrollTrigger — Scroll-Based Animation

ScrollTrigger is an official GSAP plugin that ties an animation's progress to the scrollbar — instead of playing once, the tween plays (or scrubs) as the user scrolls through a section.

index.html — add the plugin's CDN, after the core GSAP script
<script src="https://cdn.jsdelivr.net/npm/gsap@3.13.0/dist/gsap.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/gsap@3.13.0/dist/ScrollTrigger.min.js"></script>
script.js
gsap.registerPlugin(ScrollTrigger);

gsap.to(".panel", {
  x: -200,
  scrollTrigger: {
    trigger: ".panel",
    start: "top center",   // when panel's top hits viewport center
    end: "bottom center",
    scrub: true             // ties progress directly to scroll position
  }
});
Project idea

Three full-height sections that each fade and slide into view as they're scrolled into the middle of the screen.

06

Hover & Interactive Animation

GSAP tweens can be triggered by any JavaScript event, not just page load or scroll — including mouseenter and mouseleave, to make buttons and cards feel responsive.

script.js
const btn = document.querySelector(".hover-btn");

btn.addEventListener("mouseenter", () => {
  gsap.to(btn, { scale: 1.08, duration: 0.3, ease: "power2.out" });
});

btn.addEventListener("mouseleave", () => {
  gsap.to(btn, { scale: 1, duration: 0.3, ease: "power2.out" });
});
Project idea

A row of buttons or icon cards that gently scale up and lift on hover, and settle back down on mouse-leave.

07

SVG Stroke Animation

Using an SVG's stroke-dasharray and stroke-dashoffset, you can make a line or path look like it's being drawn — GSAP simply animates the offset from full-hidden to zero.

style.css
.line-path {
  stroke-dasharray: 500;
  stroke-dashoffset: 500;
}
script.js
gsap.to(".line-path", {
  strokeDashoffset: 0,
  duration: 2,
  ease: "power1.inOut",
  scrollTrigger: { trigger: ".line-path", start: "top 80%" }
});
Project idea

A simple SVG icon, underline, or squiggly line that "draws itself" the moment it scrolls into view.

08

Text Reveal Animation

To animate individual letters, split the text into one <span> per character with plain JavaScript, then stagger-animate all those spans together.

script.js
const heading = document.querySelector(".reveal-text");

heading.innerHTML = heading.textContent
  .split("")
  .map(ch => `<span>${ch === " " ? "&nbsp;" : ch}</span>`)
  .join("");

gsap.from(".reveal-text span", {
  y: 40,
  opacity: 0,
  duration: 0.6,
  stagger: 0.03,
  ease: "power3.out"
});
Project idea

A big heading that reveals itself letter-by-letter the moment the page loads, instead of just appearing instantly.

Library 02 · Lenis

Lenis — Smooth Scroll

Lenis is a small library that replaces the browser's default, slightly jerky scroll with a smoothed, "weighted" scroll feel — the kind you notice on high-end agency sites. It doesn't animate anything by itself; it just changes how scrolling feels, and it pairs naturally with GSAP's ScrollTrigger.

Getting the CDN & connecting it

Add the stylesheet in <head> and the script wherever you load GSAP — right before your own script.js, at the bottom of <body>, so Lenis already exists when your code runs.

index.html
<head>
  <link rel="stylesheet" href="https://unpkg.com/lenis@1.3.25/dist/lenis.css">
</head>
<body>
  ...
  <script src="https://cdn.jsdelivr.net/npm/gsap@3.13.0/dist/gsap.min.js"></script>
  <script src="https://cdn.jsdelivr.net/npm/gsap@3.13.0/dist/ScrollTrigger.min.js"></script>
  <script src="https://unpkg.com/lenis@1.3.25/dist/lenis.min.js"></script>
  <script src="script.js"></script>
</body>
01

What Lenis Does & Basic Setup

Lenis needs to run its own update loop alongside the browser's animation frame, so it can smooth out each scroll event before the page reacts to it.

script.js
const lenis = new Lenis();

function raf(time) {
  lenis.raf(time);
  requestAnimationFrame(raf);
}
requestAnimationFrame(raf);
Project idea

Build a long single page with 4–5 tall sections, add Lenis, and scroll it with your mouse wheel and trackpad to feel the difference against a page without Lenis.

02

Configuring the Scroll Feel

Lenis exposes a few options that shape how "weighted" the scroll feels: duration (how long it takes to settle), easing (the curve it settles with), and wheelMultiplier (how far one scroll notch moves the page).

script.js
const lenis = new Lenis({
  duration: 1.2,
  easing: (t) => Math.min(1, 1.001 - Math.pow(2, -10 * t)),
  smoothWheel: true,
  wheelMultiplier: 1
});
Project idea

Two buttons — "Snappy" and "Floaty" — that re-create the Lenis instance with two very different duration/easing combinations, so you can feel the range Lenis can produce.

03

Syncing Lenis with GSAP ScrollTrigger

Since Lenis changes how scroll position updates, ScrollTrigger needs to be told to recalculate on every Lenis scroll tick — and Lenis's own update loop should run through GSAP's ticker so everything stays in sync.

script.js
gsap.registerPlugin(ScrollTrigger);

const lenis = new Lenis();

lenis.on("scroll", ScrollTrigger.update);

gsap.ticker.add((time) => {
  lenis.raf(time * 1000);
});
gsap.ticker.lagSmoothing(0);
Project idea

Take your ScrollTrigger project from the GSAP section and add Lenis on top of it — the fade-in sections should now scroll with a smoother, weightier feel.

Library 03 · Locomotive Scroll

Locomotive Scroll

Locomotive Scroll solves a similar problem to Lenis — smooth scrolling — but takes a different approach: you mark up your HTML with data-scroll attributes, and the library handles smoothing and parallax based on those attributes directly.

Lenis vs. Locomotive Scroll

Both libraries do the same core job — smooth scrolling. You're learning both here so you know your options, but on a real project you would normally pick one, not run both at once. Lenis is lighter and pairs closely with GSAP; Locomotive Scroll is more "batteries-included," with built-in parallax via HTML attributes.

Getting the CDN & connecting it

Add the stylesheet in <head>, and the script before your own script.js at the bottom of <body> — same pattern as GSAP and Lenis.

index.html
<head>
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/locomotive-scroll@4.1.4/dist/locomotive-scroll.min.css">
</head>
<body>
  <main data-scroll-container>
    ...your sections here...
  </main>

  <script src="https://cdn.jsdelivr.net/npm/locomotive-scroll@4.1.4/dist/locomotive-scroll.min.js"></script>
  <script src="script.js"></script>
</body>
01

Setup & Data Attributes

Every page using Locomotive Scroll needs one wrapping element with data-scroll-container. The library then looks inside that container for any element tagged with data-scroll.

script.js
const scroll = new LocomotiveScroll({
  el: document.querySelector("[data-scroll-container]"),
  smooth: true
});
Project idea

Rebuild your Lenis long-scroll page using Locomotive Scroll instead, and compare how the default "feel" differs out of the box.

02

Parallax with data-scroll-speed

data-scroll-speed makes an element move faster or slower than the actual scroll — a positive number moves it in one direction relative to scroll, a negative number moves it the opposite way. Bigger numbers mean a more dramatic effect.

index.html
<div data-scroll-container>
  <section class="hero" data-scroll-section>
    <div class="bg-shape" data-scroll data-scroll-speed="4"></div>
    <h1 data-scroll data-scroll-speed="-2">Hello</h1>
  </section>
</div>
Project idea

A hero section with 2–3 layered shapes (circles, blobs, or icons) moving at different data-scroll-speed values to create a sense of depth as the user scrolls.

03

Combining Locomotive Scroll with GSAP

Locomotive Scroll emits its own scroll event with the current scroll position, which you can feed straight into a GSAP tween for extra control that plain data attributes can't give you.

script.js
scroll.on("scroll", (instance) => {
  gsap.to(".floating-icon", {
    y: instance.scroll.y * 0.1,
    ease: "none",
    overwrite: true
  });
});
Project idea

A small floating icon or shape that drifts downward at a fraction of the scroll speed, driven by GSAP but positioned using Locomotive Scroll's scroll value.

Final Step

Capstone Project Idea

Once every topic above has its own small project working, combine them into a single scrolling page. This is the project that proves you can plan and build a motion-driven page from a blank file — use it as the base for anything you build next.

"One Long Scroll" — a single-page motion experience

Structure one page as 4–5 full-height sections and bring in a technique from each topic you've learned: a text-reveal headline in the first section, a staggered card grid in the second, an SVG line that draws itself in the third, and scroll-triggered fades throughout — all wrapped in smooth scrolling from either Lenis or Locomotive Scroll (pick one). Add hover interactions to any buttons or cards along the way.
